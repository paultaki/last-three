# LAST THREE / The Broadcast

Static Three.js replay viewer. It reuses `../lib/state.js` and existing tapes. No engine changes or model calls. Build output is committed; browser runtime requires no CDN.

## Run locally

From the repository root:

```sh
npm ci --prefix web/show
npm run build --prefix web/show
npm run serve --prefix web/show
```

Open http://127.0.0.1:8843/last-three/show/ for the original stand-in cast.
Open http://127.0.0.1:8843/last-three/show/?cast=city for the private Synty cast after export.
Use `?tape=20261009-0016&i=373&cast=city` for the Pit, or `20261008-0057` for the rope rescue.

## Private character export

The purchased package stays in the shared Blender library. Run Blender with `tools/export-cast.py`, passing the vendor `POLYGON_City_Characters_SourceFiles_v3` directory and `web/show/assets/cast` output directory after `--`. See `docs/ASSET-LICENSES.md`. Do not commit the output. The exporter creates eight rigged GLBs and cast.json. Source geometry and atlas UVs remain intact; custom motion is generated by the viewer's bone poses.

## Verify

```sh
npm run check
node --test test/web/show.test.mjs
SHOW_CITY=1 node test/web/show.check.mjs
```

Browser checks require local Chrome; set SHOW_BROWSER for another installed Playwright browser channel. Screenshots containing the purchased cast stay in ignored `docs/show/screens/`. A public-safe stand-in test run omits SHOW_CITY.

Controls: play/pause, previous/next visible event, exact-event scrubber, 1x/2x/4x, chapter buttons, director mode, camera wide/cinema, graphics quality and audio. Space plays/pauses outside controls, arrows step, D toggles director. Focused controls retain native keyboard behavior. Reduced motion removes camera drift, character movement and particles.

All clocks are event-local. A settled seek is independent of previous playback. No physics engine or audio timing can change an outcome. Untrusted tape text always uses textContent or canvas text drawing.
